## Lvar to quadruples

We work with languages Lvar (simple programs with variables)

```
P ::= S | S ; P
S := print(E) | id = E
E ::= C | C + E | C - E
C ::= L | C * L | C // L | C % L | - L
L ::= A | (E) | input_int()
A ::= id | n
```

and Lqua (quadruples)

```
P ::= S | S ; P
S := print(R) | id = R
R ::= A | A + A | A - A | A * A | A // A | A // A | input_int()
A ::= id | n
```

Translate from Lvar to Lqua:

- `print(40+2)`
- `print(input_int())`
